# NREL

一个运行在命令行里的轻量 Minecraft 启动器，全屏文本界面，支持键盘与鼠标操作。

## 功能

- 查看全部官方版本（正式版 / 快照），一键安装并启动
- 自动识别本地已安装的版本
- 版本隔离：每个版本使用独立游戏目录，存档、模组、配置互不影响
- 离线登录与微软账户登录
- 官方源 / BMCLAPI 镜像源切换
- 内置命令栏，所有界面都可以直接用命令操作
- 可同时开启多个启动器线程，分别停在不同界面

## 系统要求

- Windows 10 / 11
- 已安装 Java（启动器不附带 Java）。会自动查找 `JAVA_HOME`、`PATH` 以及常见安装目录，也可以在设置里手动指定
- 首次安装版本、登录微软账户需要联网

## 安装与运行

1. 下载编译好的 `nrel.exe`，放到任意目录（例如 `D:\Games\NREL\`）。
2. 双击或在终端中运行 `nrel.exe`。
3. 首次运行会在程序所在目录自动生成 `config.json`、`.minecraft`、`.nrel-cache` 三个位置。

从源码构建：

```
cargo build --release
```

产物在 `target\release\nrel.exe`。

## 界面操作

启动后进入主界面，共五项：启动游戏、选择版本、账户管理、启动器设置、退出。

- 键盘：`↑` `↓` 循环选择，`Enter` 确认，`Esc` 返回上一级
- 鼠标：点击选项执行、滚轮切换、悬停高亮；子界面右下角有仅鼠标可点的「返回」按钮
- 主界面的 `Esc` 不会退出，必须选择「退出」（或使用 `/quit`）
- 版本选择界面：`F5` 刷新版本列表，`Tab` 在「全部 / 已安装 / 本地」之间切换，点击某个版本会直接启动

第一次启动游戏时，启动器会自动把游戏语言设为简体中文并关闭无障碍引导，下次进入游戏不会再弹出初始设置界面。

## 账户

- **离线登录**：输入一个用户名即可，适合单机与原版服务器（部分服务器要求正版则不可用）
- **微软登录**：选择后会自动复制设备码到剪贴板并给出验证地址，在浏览器中输入代码完成授权即可。登录状态会保存，下次启动无需重复登录

## 命令

在任意界面按 `/` 唤起命令栏，`Enter` 执行，`Esc` 取消；把 `/` 一起删掉会自动回到正常操作。

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/help` | `/h` `/?` | 显示命令帮助 |
| `/quit` | `/q` `/exit` | 退出启动器 |
| `/main` | | 返回主界面 |
| `/launch` | `/l` | 启动当前版本 |
| `/versions` | `/v` | 打开版本选择 |
| `/account` | `/a` | 打开账户管理 |
| `/settings` | `/s` | 打开启动器设置 |
| `/refresh` | `/r` | 刷新版本列表 |
| `/thread` | `/t` `/th` | 查看所有启动器线程 |
| `/thread new` | `/t new` | 新建线程并切换过去 |
| `/thread N` | `/t N` | 切换到第 N 个线程 |
| `/thread del N` | `/t del N` | 删除空闲线程 |
| `/version` | | 查看启动器版本与目录 |
| `/dir` | | 查看游戏目录 |

用 `/thread new` 可以一边下载安装、一边去设置或账户界面做别的事；切回某个线程时会回到它原来停留的界面。

## 设置项

- **内存分配**：给游戏分配的内存大小
- **下载源**：官方源或 BMCLAPI 镜像（国内网络建议使用镜像）
- **Java 运行环境**：自动检测，或手动选择一个 `java.exe`
- **游戏目录**：`.minecraft` 所在位置
- **版本隔离**：默认开启。开启后每个版本使用 `versions\<版本ID>` 作为独立游戏目录
- **日志等级**：`信息及以上` 或 `全部`（排查问题时选「全部」）
- **窗口分辨率 / 全屏模式 / 额外 JVM 参数**：传给游戏的启动参数

## 文件与目录

所有文件都在 `nrel.exe` 所在目录：

- `config.json`：启动器配置，每次启动都会生成/更新
- `.minecraft`：游戏目录，版本、资源、存档都在这里
- `.nrel-cache`：缓存与日志
  - `.nrel-cache\logs\YYYYMMDD-hh-mm-ss.log`：每次启动一个独立日志文件，遇到问题时可查看或反馈

## 注意事项

- **版本隔离默认开启**：开启后各版本存档互不相通，之前放在 `.minecraft\saves` 里的存档不会出现在隔离开启后的版本中。如需共用，可在设置里关闭版本隔离（新版本会共用同一个 `.minecraft`）。
- **已安装版本**：只有同时存在 `versions\<文件夹>\<文件夹>.json` 与对应 `.jar` 的版本才会被识别为已安装；识别不到时可在版本选择界面按 `F5` 刷新。
- **微软登录授权页** 显示的应用名称为 Prism Launcher（内置的公开客户端标识），不影响登录与游戏启动。
- 启动器会自动切换终端编码以保证中文正常显示，退出时会恢复原设置；如果界面出现乱码，请在支持 UTF-8 的终端（Windows Terminal）中运行。
- 删除某个版本请直接在 `versions` 下删除对应文件夹，再按 `F5` 刷新即可。
- 游戏本体日志位于游戏目录的 `logs` 文件夹，与启动器日志不是同一个位置。
