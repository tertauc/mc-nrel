# NREL

NREL 是一个在终端里运行的 Minecraft 启动器，全屏文本界面，支持键盘和鼠标。和 PCL 这类启动器相比，主要区别是 TUI、命令栏和多线程界面。

## 特有行为

- 任意界面按 `/` 打开命令栏，常用操作都能用命令完成
- 可以开多个启动器线程，各自停在不同的界面；比如一边下载安装，一边去设置或账户界面
- 主界面按 `Esc` 不会退出，要退出得选「退出」或输入 `/quit`
- 版本选择界面：`F5` 刷新，`Tab` 在「全部 / 已安装 / 本地」之间切换，点某个版本直接启动
- 第一次启动游戏时，会自动把游戏语言设为简体中文并关闭无障碍引导
- 微软登录会把设备码复制到剪贴板，登录状态会保存

## 运行

需要自己装 Java。启动器会找 `JAVA_HOME`、`PATH` 和常见安装目录，找不到就在设置里手动选 `java.exe`。

从源码构建：

```
cargo build --release
```

产物在 `target\release\nrel.exe`。

## 命令

任意界面按 `/` 唤起命令栏，`Enter` 执行，`Esc` 取消；把 `/` 删掉会自动回到正常操作。

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/help` | `/h` `/?` | 显示命令帮助 |
| `/quit` | `/q` `/exit` | 退出启动器 |
| `/main` | | 返回主界面 |
| `/launch` | `/l` | 启动当前版本 |
| `/versions` | `/v` | 打开版本选择 |
| `/account` | `/a` | 打开账户管理 |
| `/settings` | `/s` | 打开启动器设置 |
| `/refresh` | `/r` | 刷新版本列表 |
| `/thread` | `/t` `/th` | 查看所有启动器线程 |
| `/thread new` | `/t new` | 新建线程并切换过去 |
| `/thread N` | `/t N` | 切换到第 N 个线程 |
| `/thread del N` | `/t del N` | 删除空闲线程 |
| `/version` | | 查看启动器版本与目录 |
| `/dir` | | 查看游戏目录 |

## 设置与目录

版本隔离默认开启。开启后每个版本用 `versions\<版本ID>` 作为独立游戏目录，存档、模组、配置互不影响；关掉则共用 `.minecraft`。

配置在 `config.json`，游戏目录是 `.minecraft`，缓存和启动器日志在 `.nrel-cache`，日志文件为 `.nrel-cache\logs\YYYYMMDD-hh-mm-ss.log`。
